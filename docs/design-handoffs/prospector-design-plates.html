Prospector Design Plates

Seven approved screens from the two UI handoff packages that built the current Prospector interface, rebuilt from the design tool exports and rendered at full fidelity. These are the files sitting untracked in handoff/ and HANDOFF2/ at the repo root.

What these are

Each package holds a PROMPT.md build instruction, a set of reference screens exported from the design tool, and the efelle logo. The reference files are the specification: sizes, colours and spacing are readable straight out of the inline styles, which is how the build sessions consumed them.

They do not open usefully on their own. Each one is a template that expects a runtime, with sc-for and sc-if tags, mustache holes, and a design system stylesheet that was never shipped alongside them. To produce the plates below I wrote a small shim for that runtime, supplied the efelle tokens the missing stylesheet would have defined, and rendered each file in a headless browser at 1440 pixels wide.

That package was revised across three releases and re-exported in one pass, so its earliest screens describe an older app than its latest ones.

The plates

What to do with them

Every screen here is built. The two packages are spent inputs, and the design intent they carry now lives in the shipped CSS and markup, which is the version that will keep moving. A future session reading these as the current specification would be reading something the app has already left behind.

So the recommendation is to add both directories to .gitignore and keep this page as the record instead. It holds the same information in a form that does not pretend to be authoritative, weighs half a megabyte rather than two hundred, and does not need a runtime shim to look at.

The case for the opposite call is if more batches are coming in the same format. Then a tracked docs/design-handoffs/ gives each one a home and a history, and this page becomes the index.
